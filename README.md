# slot-ui

パチスロ店の日次データから「設定が良さそうな機種」をおすすめするダッシュボード。

**[→ ダッシュボードを開く](https://longpuffer.github.io/slot-ui/)**

- 抽選番号を入れると、自分の順番でも残っていそうな機種に並び替わる
- 機種ごとに直近14日の実績ストリップと、直近7日の答え合わせ付き
- 外部通信を一切しない自己完結HTML（このページ以外へ接続しない）

スコアは「直近180日のうち、その機種の設定2理論出率を超えた日の割合」。
2年695日のバックテストで上位1機種の翌日基準超え率87.2%（全機種平均66.0%）。

生成元のデータ取得・スコアリング処理はローカル環境にあり、ここには成果物のHTMLのみを置いている。
毎日自動で更新される。
